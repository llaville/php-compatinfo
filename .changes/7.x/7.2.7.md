
## 7.2.7 - 2026-10-31

> [!IMPORTANT]
>
> This is a maintenance release that still support PHP 8.1 (for the last time)
> before version 7.3.0 (that will requires PHP 8.3 or greater).

### Changed

- add support to Symfony Components v8
- migrate PHPUnit tests from annotations to attributes usage
- raise `bartlett/php-compatinfo-db` constraint to version that support PHP 8.1 until 8.5

## Fixed

- [#388](https://github.com/llaville/php-compatinfo/issues/388) : Class `Symfony\Bundle\FrameworkBundle\Command\ContainerDebugCommand` not found raised with PHAR distribution.
